# Currency Exchange Rates ETL Pipeline

Простой ETL-пайплайн (Extract, Transform, Load) для загрузки курсов валют с открытого API в базу данных PostgreSQL.

## 📋 Описание проекта

Пайплайн выполняет следующие действия:
1. **Extract**: Забирает актуальные курсы валют (базовая валюта — USD) с API `https://open.er-api.com`.
2. **Load (STG)**: Сохраняет сырой JSON-ответ в staging-слой базы данных.
3. **Transform**: Преобразует JSON в плоскую таблицу (DataFrame), извлекает дату обновления, очищает данные от дублей, пропусков и некорректных значений.
4. **Load (DWH)**: Загружает очищенные данные в целевую таблицу хранилища (DWH).

## 📂 Структура проекта

```text
.
├── config.py        # Загрузка переменных окружения и настройки API
├── extract.py       # Модуль извлечения данных из API
